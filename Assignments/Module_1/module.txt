3) What is SDLC? Explain each phase of SDLC ?

   => (SDLC):stands for Software Development Life Cycle.
            it helps developers plan, create, test, and maintain software.

            Phases of SDLC:
            1- Requirement Analysis: developers collect  and understand the user requirement.
            2- Design : developers plan how the software will work.
            3- Implementation : programmers write the actual code.
            4- Testing : the software is checked for errors or bugs.
            5- Deployment : the software is released to users.
            6- Maintenance : developers maintain the software to ensure it works as expected.
