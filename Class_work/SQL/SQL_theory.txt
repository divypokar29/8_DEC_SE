III) DQL : Data Query language:

      most most powerfull concept of sql 

      when we want to retrive records from the table we can use DQL command

      -> select

using or select command we can retrive difrent diffrent record with specific condition wise.


syntax:

-> select * from <tablename>;

e.g. ->select * from student ;

fetch specific colume from table 


syntax :
    
     -> select fieldname,fieldname2,............... from <tablename>;

     e.g.  select name,subject from student;

     fetch specific data using of condition wise
     for condition we use where clause.

     syntax: select * from <tablename> where condition;

     e.g. -> select * from student where city='ahemdabade';

     -> select name ,subjec,city.from student where city = 'ahemdabade';


     conditional operaters : 

               => , != ,> ,< ,>= ,<=

     logical operators : 

               => and, or, not
      
      membership operators :

               => in , not in , between

      pattern matching operators :
              
               => like, not like

      null operators :

               => is null , is  not null
