when we want to do some changes after executing commans we can go back ti previous command

using of TCL command

for e.g.   we order any product - add to cart - payment

but due to some resone payment is failes - at that time i want to cancel all previous Trangaction
at that time we can use TCL command

1) BEGIN : start transaction
2) COMMIT : save transaction
3) ROLLBACK : cancel transaction
4) savepoint : save specific transaction

=======================================================================
1) rollback : when we want to back to go back on starting of transaction it work like undo 

2) commit : when we want to save transaction it work like save

3) savepoint : when we want to save specific transaction it work like savepoint

4) begin : when we want to start transaction it work like begin
